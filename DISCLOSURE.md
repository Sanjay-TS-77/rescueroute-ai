# Hackathon Development Disclosure

RescueRoute AI is a new project created during the Agents for Humans Hackathon submission period.

Development uses standard tools and libraries including Python, Strands Agents SDK, FastAPI, Amazon Bedrock AgentCore SDK, pytest, and GitHub Actions. AI coding assistance from OpenAI/ChatGPT is used during implementation, review, documentation, and test generation.

No pre-existing RescueRoute application or proprietary codebase is incorporated into this submission. Synthetic demo data is newly created for the project.
